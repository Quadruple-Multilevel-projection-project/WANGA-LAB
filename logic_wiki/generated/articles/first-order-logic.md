# First-order logic

**Stable ID:** first-order-logic  
**Kind:** ESTABLISHED_REFERENCE  
**Status:** SOURCE_SUPPORTED_SUMMARY

## Definition

A formal language with names, predicates, variables and quantifiers over individuals; consequence is assessed against a defined syntax and semantics.

## Scope and limitations

Variables over individuals differ from quantification over properties or predicates.
