# Chapter Mapping Schema

כל פרק ממופה ביותר ממעבר אחד. כל מעבר הוא snapshot עצמאי.

## Pass 0 — SOURCE
נוסח מדויק, תרגום/מהדורה, מקור, חלק, פרק וגבולות הטקסט.

## Pass 1 — ספר ההיגיון
לכל משפט: סוג המשפט, נושא, נשוא, מילות קישור/יחס, משתתפים ומבנה.

## Pass 2 — TERMS
כל מונח: מופע, צורה, תפקיד, קטגוריה לפי ספר ההיגיון, הקשר מקומי ו-provenance.

## Pass 3 — PARTICIPANTS / RELATIONS
משתתפים בנפרד מהיחסים; אין להפוך מונח לישות ללא הצדקה מהטקסט.

## Pass 4 — ARGUMENT STRUCTURE
הנחות, מסקנות, תנאים, שלילות, אפשרות/הכרח ותלות בין משפטים.

## Pass 5+
קריאות חוזרות מזוויות שונות. כל קריאה מוסיפה שכבה. אין למחוק מיפוי קודם; סתירות נרשמות.

## FINAL — FIRST-ORDER LOGIC
פורמליזציה רק לאחר validation. הנוסחה היא תוצר של החילוץ, לא המקור.

SOURCE → OBSERVATION → EXTRACTION → CLASSIFICATION → VALIDATION → REPRESENTATION → FOL
