# WANGA-LAB — Logic Software Engineering Factory

**Operating-scope charter (2026-11-21):** [WANGA Engineering Factory Charter](governance/WANGA_ENGINEERING_FACTORY_CHARTER_2026-11-21.md). WANGA's primary mission is to engineer the logic-based software language, advanced algorithms, analytical-agent runtime, processor interfaces, integration, and verification infrastructure. External universities, laboratories, and research organizations conduct scientific research; a separate Global Research Liaison / Directorate coordinates those relationships. WANGA is not intended to duplicate a research institute.

**Engineering assurance:** Existing evidence integrity, provenance reconstruction, drift forensics, and verification components are retained where they directly support software quality and system integrity. Their presence in this repository does not make WANGA the owner of external scientific research.

**AI231 Global Neural Governance — T15 / 500-second integration:** [Architecture and service specification](docs/GLOBAL_NEURAL_GOVERNANCE_T15_500S_INTEGRATION.md) — a development proposal; deployment and legal authority are not claimed.

## Delivery rule

A directory, prompt, agent identity, workflow, or configuration file is not proof of an implemented capability. Every claimed capability needs a named commit, executable tests, retained evidence, and independent review. See the charter for task intake, role separation, acceptance criteria, and definition of done.
