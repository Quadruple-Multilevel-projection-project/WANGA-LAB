# Scientific Baseline & Parameter Notes

Status: INITIAL / EXPERIMENTAL

The research workspace may represent complex system behavior through measurable structural constraints, including:

- baseline and delta measurements;
- topology and node relationships;
- dependency and configuration state;
- boundary and separation conditions;
- reproducibility constraints;
- evidence lineage and observation context.

Numerical parameters are research data only when a source, derivation, or experiment supports them. Placeholder parameters must remain explicitly marked as such.
