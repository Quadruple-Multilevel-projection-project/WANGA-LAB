# 20. מפת הדרכים למעבר של האקוסיסטם

**אשכול 5 · מצב המימוש: PARTIAL — component roadmaps exist; integrated ecosystem plan is planned**

## מטרה
לארגן את המעבר ממחקר וחבילות ניתנות לבדיקה לתהליך תרומה, ממשק תפעולי, קטלוג ושימוש; תגמול מגיע רק אחרי שהכללים מוגדרים.

## העיקרון המערכתי
הסדר חשוב: package contract לפני bounty; tests ו-review לפני reward; מודל שימוש לפני עמלות; אבטחה וסקירה משפטית לפני token issuance. הכרזה אינה תוצאה.

## משמעות עסקית
שלבים מדידים מצמצמים סיכון לכך שהאתר יבטיח יכולת שלא נבנתה. הם גם מאפשרים למשקיעים לראות תוצרים ולמהנדסים להצטרף עם משימות ברורות.

## מצב GitHub שנבדק
קיימים roadmaps ותוצרי מחקר, אך לא נמצאה מפת דרך מאוחדת המחברת את כל 20 המאמרים, התגמולים, marketplace וה-gates המשפטיים.

## מה חסר ומשימות
נדרשים dependencies, owners, dates, budgets, exit criteria, legal/security gates ו-public status registry. אין להציג מניעת קריסה כללית כתוצאה מובטחת.

## תנאי קבלה
כל milestone מציין תלות, ראיה, owner/role ותנאי קבלה; חסימות מוצגות; אין קפיצה מהיפותזה להשקה מסחרית.
