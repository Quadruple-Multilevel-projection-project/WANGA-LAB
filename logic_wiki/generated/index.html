Logic

Logic studies valid reasoning and formal systems for representing and assessing arguments. A formal logic typically specifies a language, a deductive system and/or model-theoretic semantics.

Boundary: General reference summary; it does not imply every natural-language utterance is already formalized.

Sources: Classical Logic

ESTABLISHED_REFERENCE · SOURCE_SUPPORTED_SUMMARY

First-order logic

A formal language with names, predicates, variables and quantifiers over individuals; consequence is assessed against a defined syntax and semantics.

Boundary: Variables over individuals differ from quantification over properties or predicates.

Sources: Classical Logic forall x: Calgary

Related: Logic Second-order logic Formal language

ESTABLISHED_REFERENCE · SOURCE_SUPPORTED_SUMMARY

Second-order logic

An extension of first-order logic that may quantify over properties, relations or sets, depending on the formulation and semantics.

Boundary: Higher-level architecture is not, by itself, a formal definition of second-order logic; the chosen semantics matter.

Sources: Second-order and Higher-order Logic

Related: First-order logic Metalogic

Formal language

A vocabulary and grammar formally determining which strings are well-formed. Meaning and validity require an interpretation or semantic system beyond syntax alone.

Boundary: Syntax validity does not by itself establish truth, meaning in a target domain, or empirical support.

Sources: Classical Logic forall x: Calgary
