# Evidence and Verification Statuses

Page ID: WIKI-EVIDENCE-001  
Status: PROJECT POLICY  
Related: M/L/N Continuous Field; Fractal Logic; Neural Thinking Machine.

## Core states
- BUILT: implementation/data artifact exists.
- SPECIFIED: requirements exist; implementation may not.
- PROTOTYPED: bounded implementation exists.
- TESTED: named tests have reproducibly passed.
- VERIFIED: a narrowly scoped claim passed its defined independent verification procedure.
- HYPOTHESIS: proposed interpretation to evaluate.
- NOT_YET_VERIFIED: available evidence is insufficient.
- NOT_FOUND_IN_SEARCH: the named search scope did not locate a source; this does not prove nonexistence.

## Non-equivalences
A syntax check is not semantic verification. A URL is not proof that the source supports a claim. Deterministic replay is not proof of truth. Goal satisfaction under supplied rules does not independently verify premises. Confidence is not evidence. A numerical balance score is not a truth value.

## Required verification record
Store the scoped claim, source/version/locator, test procedure, expected and observed result, date, tester/tool version, limitations and evidence artifact. Status upgrades apply only to the tested claim and exact conditions.
