# WANGA Logic Wikipedia — Research Workstream V1

Status: INITIAL KNOWLEDGE BASE STRUCTURED; SOURCE COVERAGE IN PROGRESS.

This is a versioned encyclopedia for the logic research program. Every article separates source text, formal derivation, project hypothesis and open question.

## Content contract
Every page has a stable page ID and slug, title and aliases, abstract/body, concepts, parent/child IDs and backlinks, claim records with source locator/status, formulas with assumptions, related fragment/model IDs, review state, version and change log.

## Editing policy
1. No sourced claim without source ID and locator.
2. No model-derived claim automatically becomes VERIFIED.
3. Every formula lists assumptions and normalization requirements.
4. Disagreement is represented as parallel alternatives, not silently overwritten.
5. Internal links must resolve and backlinks must be generated.
6. Model-generated proposals remain drafts until source, logic and test checks pass.

Repository automation can rebuild the link index, check links/schemas, run examples and produce a dated report. It cannot mine private conversation transcripts unless they are explicitly accessible.
