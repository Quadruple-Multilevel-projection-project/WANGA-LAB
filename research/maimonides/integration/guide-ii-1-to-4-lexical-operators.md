## 20. מבנה משפט מינימלי

Each sentence in B:א–ד can be normalized as:

    [Operator]
       ↓
    [Subject / Node]
       ↓
    [Predicate / Relation]
       ↓
    [Condition / Scope]
       ↓
    [Cause / Priority / Potentiality / Finality]
       ↓
    [Conclusion / Rejection / Attribution]

## 21. Rule: small words are structural

Example:

    "אם"
      = opens branch

    "אם כן"
      = closes branch with conclusion

    "אמנם"
      = switches branch while preserving prior branch

    "אלא"
      = replaces/limits prior interpretation

    "עד ש"
      = defines terminal point

    "רצוני לומר"
      = precision operator

    "כלומר"
      = semantic normalization

    "לא תחשוב"
      = blocks invalid inference

    "ודע"
      = marks a node for future retention
