# Automation and Compute Plan V1

## Unattended work that is realistic
- Repository-local tests, schema checks, freshness checks and link validation on push/PR.
- A weekly repository workflow producing a dated report artifact.
- Periodic search of sources genuinely exposed through the connected GitHub/Wix/chat archive tools.
- Additive Wix publication only after source/status checks and a public read-back.

## Source access limits
Private ChatGPT conversations are not available as a general filesystem. Process only currently accessible conversation material, indexed library items or explicit exports. Record all access gaps. Do not claim continuous collection from sources that are not accessible.

## Weekly research cycle
1. Search available archive/project conversations and log coverage.
2. Check canonical GitHub sources and Wix page inventory.
3. Hash and index new material.
4. Propose literal spans, logic fragments, alternatives and conflict candidates.
5. Run schema, source, backlink, replay and regression tests.
6. Produce a dated Markdown and JSON report.
7. Open/update a GitHub PR for code or corpus changes.
8. Publish additive wiki updates only after source/status checks; keep a version/deployment record and verify public read-back.
9. A no-change report is valid. Never invent additions just to show activity.

## Compute and cost
Start CPU-only: deterministic Python, JSON/Markdown indexes, graph validation, composition tests and GitHub Actions. Use an optional LLM only with an explicit provider/endpoint, cost cap and logging. Default paid-model budget is zero. Use GPU only after a benchmark demonstrates benefit.

## Schedule limits
A recurring ChatGPT automation supports daily/weekly/monthly schedules, not an always-on loop. GitHub Actions can run repository checks independently; neither mechanism can read private conversations without access nor publish to Wix without the authorized connector/configuration.

## Publication safety
Publisher may auto-publish additive source-backed pages with status and version metadata. It may not delete disputed material, change canonical definitions without a review, publish raw private conversations, upgrade hypotheses to verified, or trigger external actions from unverified recommendations.
