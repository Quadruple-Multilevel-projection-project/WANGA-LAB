# WANGA-LAB Agent Network

Infrastructure boundary model: 4 infrastructure agents × 3 depth layers = 12 operational cells.

Agents are roles; runtime instances and model slots are separate concerns.

## Boundary rule
Each infrastructure agent owns a 90° operational domain. Cross-domain movement requires an explicit interface/handoff. No agent may acquire another domain's authority merely by communicating with it.

## Core agents
- OR-01 Orchestrator — task, scheduling, routing, coordination; cannot alter evidence or determine truth.
- BR-01 Browser — external-world navigation, retrieval, forms, observations; cannot verify claims.
- DO-01 Documents — document extraction, OCR, structure; cannot determine meaning beyond extraction.
- AU-01 Audit Guardian — evidence, provenance, verification gates; cannot perform research in place of research agents.

## Path invariant
Every active agent must have: Current Position, Permitted Domain, Next Permitted Transition, Boundary Condition, Evidence of Transition.

## Status semantics
Observation ≠ Verification. Routing ≠ Authority. Symbol ≠ Model ≠ Physical Reality.

## Research Agent Layer

The Vitruvius/Rambam forensic network adds six specialized research roles under OR-01:

- VIT-SOURCE — primary De Architectura extraction, editions, locators, chapter boundaries.
- RAMBAM-SOURCE — primary Rambam extraction and division mapping.
- FORMALIZER — source-grounded Logic Kernel formalization only.
- CROSS-CORPUS — structural correspondence and independent representation tests.
- CLAIM-FORENSIC — isolated audits of the 50-chapters and 32-core claims.
- DELTA-REPORTER — delta-only compilation of upstream findings.

OR-01 remains the sole orchestrator. It routes and enforces gates; it does not determine truth or alter evidence status.

The single source of truth for responsibilities is:
`agents/AGENT_RESPONSIBILITY_MATRIX_V1.yaml`

Runtime topology:
`runtime/research-agent-network.yaml`

The deterministic route-only queue is generated by:
`scripts/build_research_agent_work_queue.py`

### Hard research invariants

- No agent changes another agent's evidence status.
- Every finding carries `source_agent` and a complete `evidence_chain`.
- WANGA-internal material cannot authenticate a historical claim.
- Negative findings and `NOT_SUPPORTED` remain first-class results.
- Corpus-level conclusions require Books I-X or an explicit `CORPUS_COVERAGE_GAP`.
- Conceptual geometry is not automatically a computational operator.
- Structural similarity is not proof.
