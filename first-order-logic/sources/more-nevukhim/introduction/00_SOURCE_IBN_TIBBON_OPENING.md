- ספר ההיגיון משמש כלי ניתוח בלבד; פרק י"ג של ספר ההיגיון אינו חלק מהסיווג המבוקש לפתיחה.
- סוגי השמות "משתתפים / מושאלים / מסופקים" נשארים פתוחים עד לבדיקה ייעודית מתוך מורה הנבוכים.
