# הקדמת מורה הנבוכים — מרכז בקרה

מזהה: MN-INTRODUCTION-CORE

## תפקיד

הקדמת מורה הנבוכים משמשת שכבת בקרה מתודולוגית לקריאת כל פרקי מורה הנבוכים.

היא אינה מחליפה את המקור ואינה מהווה פירוש חיצוני. היא מרכזת את כללי הקריאה שהפרויקט מפיק מן ההקדמה עצמה.

## כלל מרכזי

כל פרק במורה הנבוכים נקרא גם לאור ההקדמה, וכל קושי שאינו מוכרע נבדק תחילה מול כללי ההקדמה לפני שמכניסים פירוש חיצוני.

## מסלול בדיקה

`פרק → שאלה → הקדמת מורה הנבוכים → כלל קריאה → בדיקה בפרקים אחרים → חזרה לפרק`

## סדר מקורות

1. נוסח מורה הנבוכים עצמו.
2. כללי הקריאה העולים מן ההקדמה.
3. בדיקה מול פרקים אחרים במורה הנבוכים.
4. ספר ההיגיון ככלי ניתוח.
5. מקור חיצוני רק כאשר הבעיה עדיין אינה מוכרעת.

## כלל מתודולוגי

אין להשלים פער באמצעות השערה כאשר ניתן לבדוק את הסוגיה בתוך מכלול מורה הנבוכים.

אם הקריאה עדיין אינה מוכרעת לאחר הבדיקה — מסמנים אותה כפתוחה ואינם הופכים אותה לפרשנות מחייבת.
