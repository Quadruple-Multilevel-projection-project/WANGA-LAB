# Constructive Sentence Corpus — C25–C50

Status: `SPECIFIED / DERIVED-CONSTRUCTION`

These are new formal constructions derived from the structures C01–C24 supplied in the research model. They are not quotations from Maimonides and are not claims about Maimonides' historical wording.

## A. Separation of content from metadata

### C25 — Same content, different epistemic status
> האדם לומד.

```text
Content = אדם → לומד
EpistemicSource = Sense
TruthStatus = TRUE
```

The same proposition may be stored with a different source without changing its logical content.

### C26 — Source change does not change proposition
> האדם לומד.

```text
P = אדם → לומד
Source(P) = FirstIntelligible
Source(P) ≠ Content(P)
```

### C27 — Unknown proposition
> האדם לומד.

```text
P = אדם → לומד
TruthStatus = UNKNOWN
```

`UNKNOWN ≠ FALSE`.

### C28 — False proposition
> האדם אינו לומד.

```text
P = אדם → ¬לומד
TruthStatus = FALSE
```

The status of a proposition is stored separately from its syntactic form.

## B. Quantity and quality without collapsing them

### C29 — Universal affirmative
> כל תלמיד הוא לומד.

```text
Subject = תלמיד
Predicate = לומד
Quantity = Universal
Quality = Affirmative
```

### C30 — Universal negative
> שום תלמיד אינו לומד.

```text
Subject = תלמיד
Predicate = לומד
Quantity = Universal
Quality = Negative
```

### C31 — Particular affirmative
> קצת מן התלמידים לומדים.

```text
Subject = תלמידים
Predicate = לומדים
Quantity = Particular
Quality = Affirmative
```

### C32 — Particular negative
> קצת מן התלמידים אינם לומדים.

```text
Subject = תלמידים
Predicate = לומדים
Quantity = Particular
Quality = Negative
```

Together:

```text
                Quality
             +            -
Universal    C29          C30
Particular   C31          C32
```

This is a controlled four-cell sentence matrix, not a claim that the source uses this exact table.

## C. Predicate preservation across quantity

### C33 — Quantity rotation
> כל תלמיד הוא לומד.
> קצת מן התלמידים לומדים.
> ראובן לומד.

```text
Predicate = לומד
Quantity = Universal → Particular → Individual
```

The predicate remains fixed while the scope changes.

### C34 — Quality rotation
> התלמיד לומד.
> התלמיד אינו לומד.

```text
Subject = תלמיד
Predicate = לומד
Quality = Affirmative ↔ Negative
```

### C35 — Quantity + quality rotation
```text
Universal + Affirmative
Universal + Negative
Particular + Affirmative
Particular + Negative
```

A sentence can therefore be transformed at the level of quantity or quality without silently changing the predicate.

## D. Time and modality as external layers

### C36 — Temporal preservation
> ראובן לומד.
> ראובן היה לומד.
> ראובן יהיה לומד.

```text
Content ≈ ראובן → לומד
Time = Present | Past | Future
```

### C37 — Modal preservation
> ראובן ילמד.
> אפשר שראובן ילמד.
> הכרחי שראובן ילמד.

```text
Content = ראובן → ילמד
Modality = None | Possible | Necessary
```

### C38 — Time × modality
> אפשר שראובן ילמד מחר.

```text
Content = ראובן → ילמד
Modality = Possible
Time = Future
```

The system stores temporal and modal information as separate dimensions.

## E. Negation scope

### C39 — Negation of predicate
> ראובן אינו לומד.

```text
¬(ראובן → לומד)
```

### C40 — Negation of modality
> אין הכרח שראובן ילמד.

```text
¬Necessary(ראובן → ילמד)
```

This is not automatically equivalent to:

```text
Necessary(ראובן → ¬ילמד)
```

The scope of negation must be stored.

### C41 — Possibility of negation
> אפשר שראובן לא ילמד.

```text
Possible(ראובן → ¬ילמד)
```

This must not be collapsed into `¬Possible(ראובן → ילמד)` without an explicit logical rule.

## F. Premise packaging

### C42 — Proposition promoted to premise
> כל לומד הוא אדם.

```text
Sentence
↓
Proposition
↓
Premise
```

Promotion to `PREMISE` is a role assignment; it does not by itself prove the proposition.

### C43 — Premise with source
> כל לומד הוא אדם.

```text
Premise = P
EpistemicSource = FirstIntelligible
TruthStatus = TRUE
```

### C44 — Premise with unsatisfied condition
> כל לומד הוא אדם.

```text
Premise = P
TruthStatus = TRUE
InferenceCondition = UNSATISFIED
```

Therefore:

```text
TRUE(P) ≠ INFERABLE(P)
```

Truth and inferential admissibility are separate fields.

## G. Inference gates

### C45 — Valid chain
> כל לומד הוא אדם.
> כל אדם מדבר.
> לכן כל לומד מדבר.

```text
P1: A → B
P2: B → C
Middle = B
Conclusion: A → C
Gate = OPEN
```

### C46 — Missing middle
> כל לומד הוא אדם.
> כל אדם מדבר.
> לכן כל לומד כותב.

```text
P1: A → B
P2: B → C
RequestedConclusion: A → D
Middle = B
RequiredRelation(A,D) = ABSENT
Gate = BLOCKED
```

The presence of two premises does not authorize an arbitrary conclusion.

### C47 — Contradictory premises
> כל לומד הוא אדם.
> שום לומד אינו אדם.

```text
P1 = A → B
P2 = A → ¬B
Conflict = DETECTED
InferenceStatus = BLOCKED
```

The system records the contradiction before attempting a conclusion.

### C48 — Unknown premise blocks demonstration
> כל לומד הוא אדם.
> כל אדם מדבר.

```text
P1 = TRUE
P2 = UNKNOWN
Conclusion = A → C
DemonstrativeStatus = BLOCKED
```

`BLOCKED` does not mean the conclusion is false.

## H. Hidden-premise control

### C49 — Hidden bridge
> כל לומד הוא אדם.
> [הקדמה נסתרת]
> לכן כל לומד מדבר.

```text
VisiblePremise = A → B
HiddenPremise = B → C
Conclusion = A → C
HiddenPremiseStatus = UNVERIFIED
Gate = BLOCKED
```

### C50 — Exposed bridge
> כל לומד הוא אדם.
> כל אדם מדבר.
> לכן כל לומד מדבר.

```text
HiddenPremise → ExposedPremise
Verification = AVAILABLE
Gate = OPEN
```

The transition is:

```text
Hidden → Exposed → Checked → Admissible
```

## Corpus rule

The constructions above add one explicit invariant:

```text
Sentence
→ Proposition
→ Premise
→ Condition Check
→ Inference
→ Conclusion
```

At every transition, the system must preserve the distinction between:

- content,
- quantity,
- quality,
- time,
- modality,
- epistemic source,
- truth status,
- inference conditions,
- conclusion status.

No construction in this file is a quotation from the source.
