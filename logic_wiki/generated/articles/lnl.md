# Logic-Native Language (LNL)

**Stable ID:** lnl  
**Kind:** WANGA_IMPLEMENTED_PROTOTYPE  
**Status:** BUILT_NOT_SEMANTICALLY_VERIFIED

## Definition

A prototype declarative language with source, fact, rule, goal and constraint statements; its compiler produces a model graph and execution bundle for the WANGA symbolic kernel.

## Scope and limitations

LNL/0.1 is a small typed syntax; it is not a trained model and does not formalize arbitrary natural language.
