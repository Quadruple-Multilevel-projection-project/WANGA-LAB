# Logic Catalog

Purpose: extract reusable logic primitives from WANGA-LAB and compose minimal bundles with maximum verified coverage.

Status: PLANNED

Targets:
- 50 candidate primitives
- 100 candidate bundle configurations
- identify the smallest verified bundles with the widest capability coverage

Commercial direction:
- Human engineers are an initial discovery and reputation channel.
- The long-term primary market is machine-discoverable Logic for AI agents.
- Bundles should solve a defined problem with the fewest required primitives.
- Configuration should be machine-readable so an agent can evaluate compatibility and request or trigger configuration.
- Partner/referral distribution is a future channel: partners may introduce engineers, teams, or agents and receive a defined share of attributable sales.
- The catalog should support both human browsing and machine discovery.

Required product metadata for future machine discovery:
- purpose
- capabilities
- inputs / outputs
- constraints
- dependencies
- compatible runtimes
- configuration parameters
- tests / evidence
- verification status
- version
- price / commercial route
- discovery / referral attribution where applicable

Rules:
- no claim of uniqueness without evidence
- no VERIFIED status without tests/evidence
- preserve source lineage
- distinguish primitive, bundle, configuration, and custom logic
- do not optimize for bundle count alone; optimize for verified capability coverage with minimal components
