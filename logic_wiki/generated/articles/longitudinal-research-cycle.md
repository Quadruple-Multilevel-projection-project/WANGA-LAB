# Longitudinal logic research cycle

**Stable ID:** longitudinal-research-cycle  
**Kind:** WANGA_PROCESS_PROPOSAL  
**Status:** DAILY_AUTOMATION_ENABLED_WITH_ACCESS_BOUNDARIES

## Definition

A repeatable process that checks available sources, registers new evidence, extracts and normalizes logic, composes candidates, runs adversarial and benchmark checks, evaluates readiness, generates a dated report and updates approved public summaries.

## Scope and limitations

Scheduled runs operate only on accessible inputs and connected tools. They cannot fetch private conversation history unless an export is provided. A no-change, blocked or failed run is a valid result; publication requires source/provenance checks and Wix read-back.
