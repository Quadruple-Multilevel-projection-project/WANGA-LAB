# Logic Before Weight

Page ID: WIKI-LOGIC-WEIGHT-001  
Status: PROJECT CONTRACT  
Related: Fractal Logic; Evidence and Verification Statuses.

## Contract
source lineage → literal extraction → semantic structure → relation extraction → first-order logic → second-order/meta-logic → logical closure and relation checks → configuration → weights

A weight is not permitted to invent a missing source, relation, premise or rule. Numerical tuning starts only after the structure needed for the task is explicit enough to test.

## Why the order matters
A model may learn statistical correlation without preserving source boundaries. Conversely, a symbolic rule is not true merely because it is written down. Both evidence and explicit model assumptions must precede weight tuning.

## Acceptance record
Record source IDs and literal spans; extracted terms and relations; declared formalism; closure/contradiction/boundary results; configuration and weight version; tests before/after tuning; rollback state.
