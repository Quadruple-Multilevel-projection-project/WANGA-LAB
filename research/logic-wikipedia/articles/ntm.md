# Neural Thinking Machine (NTM)

Page ID: WIKI-NTM-001  
Status: ARCHIVED V0.1 BASELINE; EXTENDED PROTOTYPE NEEDS REPOSITORY INTEGRATION CHECK  
Related: M/L/N Continuous Field; Evidence and Verification Statuses; Fractal Logic.

## Purpose
NTM is the orchestration layer intended to hold task state, evidence references, source versions, unresolved questions, alternative readings, replay identity and candidate/verification status.

The preserved archive NTM_v0_1_executable_core.zip contains ATLAS, 28 named thought modes, a MIRROR counter-reading placeholder, evidence ledger, unresolved-state output, deterministic replay and SHA-256 state identity. Listing a mode is not the same as implementing it; inspect which modes execute real logic.

## Connection to MLN and LNL
- MLN supplies continuous measurement/operator diagnostics and candidate subblocks.
- NTM records state, runs bounded analysis paths, maintains unresolved questions and replay/evidence bookkeeping.
- LNL provides explicit source/fact/rule/goal/constraint declarations.

Do not collapse these into one untyped object. Each layer has a distinct acceptance contract.

## Verification boundary
NTM is not evidence that an underlying interpretation is true. MIRROR reversal is a counter-reading candidate; contradiction heuristics are review triggers; numerical drift is not causal attribution.
