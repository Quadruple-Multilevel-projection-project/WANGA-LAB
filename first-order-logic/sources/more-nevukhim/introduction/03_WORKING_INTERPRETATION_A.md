## מגבלה

אין בשלב זה לקבע את השמות כמשתתף / מושאל / מסופק.

הסיווגים הללו ייבדקו בהמשך מתוך המקור עצמו ובאמצעות השוואה למכלול מורה הנבוכים.

## סדר עבודה

1. SOURCE — נוסח המקור.
2. DECOMPOSITION — פירוק המשפט.
3. MILOT-HIGAYON — בדיקה בכלי ספר ההיגיון.
4. CLASSIFICATION — סיווג רק לאחר שהקריאה יציבה.
5. CROSS-CHECK — בדיקה לאחור ומול פרקים אחרים.
6. FORMALIZATION — ייצוג פורמלי רק לאחר השלבים הקודמים.
