# מורה נבוכים — ספריית מקורות

## תפקיד

זוהי שכבת המקור הראשית של חומר **מורה נבוכים** בתוך פרויקט הלוגיקה מסדר ראשון.

הספרייה מפרידה בין:

1. **SOURCE** — נוסח מקור חיצוני.
2. **BIBLIOGRAPHIC RECORD** — זיהוי המהדורה/תרגום/פרק.
3. **EXTRACTION** — חילוץ טקסטואלי מתוך המקור.
4. **ANALYSIS** — פירוק לשוני/לוגי שנעשה בפרויקט.
5. **FORMALIZATION** — ייצוג פורמלי מאוחר יותר.

אין לערבב בין השכבות.

## מקור בסיס

**מורה נבוכים בתרגום רבי שמואל אבן תיבון — ויקיטקסט.**

הקטגוריה בוויקיטקסט כוללת 231 דפים, הכוללים את דפי היצירה, דפי ביאור, פתיחות ופרקי שלושת החלקים. מספר הדפים אינו מספר הפרקים של היצירה.

Source URL:
https://he.wikisource.org/wiki/קטגוריה:תרגום_אבן_תיבון_למורה_נבוכים

## חלוקת היצירה

- חלק א: פרקים א–עו
- חלק ב: פרקים א–מח, וכן דף ההקדמות
- חלק ג: פרקים א–נד

## כלל עבודה

כל הפניה בפרויקט למורה נבוכים צריכה להיות ניתנת לשחזור באמצעות:

`part + chapter + source`

לדוגמה:

`MN-I-28 / Ibn-Tibbon / Wikisource`

ולא רק "מורה נבוכים".

## גבול

הקבצים בספרייה זו אינם טוענים שהסכמה הלוגית של הפרויקט היא הסכמה של הרמב"ם. כל סימון לוגי הוא שכבת חילוץ/ניתוח נפרדת.
