# מורה נבוכים — חלק I, פרק 11

מזהה: MN-I-11

## עקרון העבודה

הפרק הזה הוא מאגר עצמאי בתוך ספריית המקורות של פרויקט הלוגיקה מסדר ראשון.

אין לבצע כאן קריאה יחידה. הפרק ימופה בשכבות חוזרות ועצמאיות, כאשר כל מעבר מוסיף מידע ואינו מוחק את המיפוי הקודם.

## שכבות מיפוי

1. SOURCE — נוסח הפרק כפי שהוא במקור.
2. SENTENCE-SEGMENTATION — חלוקת הטקסט למשפטים/יחידות טקסטואליות.
3. MILOT-HIGAYON-CLASSIFICATION — סיווג כל משפט לפי מערכת ספר ההיגיון.
4. TERMS — חילוץ המילים והמונחים והקטגוריה שלהם.
5. SUBJECT-PREDICATE — זיהוי נושא, נשוא ותוספות.
6. PARTICIPANTS — זיהוי המשתתפים/אובייקטים/מעמדות שהמשפט מדבר עליהם.
7. RELATIONS — חילוץ היחסים בין המשתתפים.
8. QUANTIFICATION — כמתים, היקפים, כלליות ופרטיות.
9. NEGATION-MODALITY — שלילה, אפשרות, הכרח, איסור ותנאים.
10. ARGUMENT-STRUCTURE — הנחות, מסקנות, נימוקים ותלות בין משפטים.
11. REPEATED-PASSES — מיפוי חוזר מזוויות שונות.
12. FIRST-ORDER-FORMALIZATION — פורמליזציה מסדר ראשון רק לאחר שהשכבות הקודמות מתועדות.

## כלל יסוד

אין להמיר משפט ישירות לנוסחת FOL.

SOURCE → OBSERVATION → EXTRACTION → CLASSIFICATION → STRUCTURAL ANALYSIS → VALIDATION → FORMALIZATION
