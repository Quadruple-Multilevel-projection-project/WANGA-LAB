## 2. א:כח — רגל: מופע משמעותי ביחס
NAME: רגל מתפצל לפי הקשר:
- רגל → איבר
- רגל → המשך
- רגל → סיבה / בגלל

יחס המשך: X ברגלי Y → X נמשך אחר Y.

יחס סיבתי: X בגלל Y → Y הוא סיבה ל-X. כיוון היחס נשמר.

עמדו רגליו: נשמרת ההבחנה Cause(X) ≠ Persistence(Cause(X)).

באותו חומר נשמר גם:
- חומר ראשון → מקבל / מתפעל
- צורה → פועלת
- חומר ראשון ≠ צורה

ודע: הוראת שמירת עיקרון/צומת להמשך; לא מילת מילוי.

## 3. א:סט — ארבע הסיבות והשתלשלות
עילה / סיבה / פועל מופיעים גם כמינוחים מיוחסים; לכן Attribution ≠ Assertion.

נשמרת ההבחנה Potential ≠ Actual. בדוגמת הבונה: בונה בכוח → בונה בפועל → דבר נבנה.

ארבע הסיבות נשמרות כשדות נפרדים:
- MATERIAL_CAUSE = חומר
- FORMAL_CAUSE = צורה
- EFFICIENT_CAUSE = פועל
- FINAL_CAUSE = תכלית

קרוב ורחוק נשמרים יחד:
CAUSE_REMOTE → מתווכים → CAUSE_NEAR → effect

חיפוש סיבה הוא רקורסיבי: Causeᵢ(X) → Search(Cause(Causeᵢ(X))).

## 4. א:סט — צורה, חומר ותלות
prior form → prepares matter → matter receives next form.

יש לשמור בנפרד: MATTER, FORM, PREPARATION, RECEPTION, DEPENDENCE.

גבול מפורש בחומר: Formal dependence ≠ Material identity. אין לזהות אוטומטית את הצורה האחרונה עם צורה טבעית חומרית.

## 5. א:סט — שרשרת התכליות
Goal(X) → Search(Goal(Goal(X))).

בדוגמת הכיסא חולצו:
- חומר → עץ
- פועל → נגר
- צורה → ריבוע
- תכלית → ישיבה

בהמשך התכלית נעשית שרשרת של תכליות. לכן יש לשמור PURPOSE, PURPOSE_TARGET, PURPOSE_DEPTH, PURPOSE_CHAIN.

## 6. ב:א — מניע, מונע ושרשרת
מניע → חומר → קבלת צורה.

מניע קרוב → מה הניעו? → מניע נוסף.

שרשרת האבן שנמצאת במאגר:
מקל → אבן
יד → מקל
מיתרים → יד
עורקים → מיתרים
עצבים → עורקים
חום טבעי → עצבים
צורה שבגוף → חום טבעי

היחידה היא MOVER → MOVES → MOVED, עם עומק שרשרת.

חשוב: FIRST_IN_CHAIN נשמר בנפרד מ-ULTIMATE_FIRST_CAUSE.

## 7. ב:א — ארבע חלופות והפעלת דחייה
מניע הגלגל מתפצל לארבע אפשרויות:
1. גוף חיצוני
2. נבדל ממנו
3. כוח מתפשט
4. כוח בלתי מתחלק

זהו חומר גלם ל-EXHAUSTIVE_DIVISION, BRANCH, REJECTION, CONTRADICTION, SURVIVING_BRANCH.

המשפט יכול לפתוח ענף, לבדוק אותו, לדחות אותו או להשאירו; הוא אינו רק נושא → נשוא.

## 10. סכמת החילוץ המאוחדת — עדיין לא ארכיטקטורה
TEXT SPAN → NAME / TERM → SENSE → SUBJECT / PREDICATE → RELATION → DISTINCTION → CONDITION / MODALITY / NEGATION → CAUSE TYPE → CAUSE DEPTH → TRANSFORMATION / TRANSFER / ACTUALIZATION → COMBINATION / DIVISION → INFERENTIAL ROLE.

CAUSE TYPE נשמר כארבעה שדות: MATTER, FORM, AGENT, PURPOSE.
CAUSE DEPTH נשמר כ-NEAR / REMOTE.
INFERENTIAL ROLE כולל PREMISE, BRANCH, REJECTION, CONSEQUENCE, ATTRIBUTION, CONCLUSION.

הסכמה היא Extraction Schema בלבד. אין כאן טענה שהרמב״ם בנה מערכת כזו.
