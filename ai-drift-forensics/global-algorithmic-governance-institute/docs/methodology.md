# Causal Attribution & Verification Methodology

Status: SPECIFIED / INITIAL

Core sequence:

```text
Baseline → Observation → Drift Detection → Evidence Preservation → Reconstruction → Causal / Dependency Analysis → Attribution → Risk Quantification → Intervention → Verification
```

The institute layer treats these as separate evidentiary questions. A finding in one stage does not automatically establish the conclusion of a later stage.

## Minimum controls

1. Preserve the observed state and relevant context.
2. Normalize representations before comparison.
3. Record the baseline and the comparison condition.
4. Reproduce under controlled conditions where feasible.
5. Keep competing explanations explicit.
6. Separate technical evidence from legal, regulatory, insurance, and economic conclusions.
7. Record verification status independently from implementation status.
