## Definition

A bounded coordinator that connects the Logic Wiki catalog, candidate fractal composer, typed-fragment checks, source-provenance gate, counter-reading candidate, and existing six-role agent integration suite. The Logic Trader ranks assets by lexical overlap and source/link metadata, assembles an internal candidate logic package, and preserves source IDs and hashes.

## Scope and limitations

Lexical ranking is not semantic relevance. The runtime is local and deterministic; P2P transport, replicated network CRDTs, biological connectome execution, external model calls, and automatic release are not implemented.
