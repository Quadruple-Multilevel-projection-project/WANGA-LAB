# Rolling 24–36 Month Innovation Horizon

Status: PLANNED

## Purpose

Maintain a continuously updated view of the product layer that is likely to emerge above today's agent infrastructure.

This is a rolling horizon, not a fixed forecast.

## Monthly cycle

Every month:

1. Collect newly emerged capabilities, standards, platforms, protocols, agent patterns, and commercial models.
2. Separate durable signals from short-lived announcements.
3. Identify what is becoming infrastructure/commodity.
4. Identify the next higher abstraction layer becoming commercially and technically relevant.
5. Map that layer to capabilities we could package as Logic, Bundles, or Agent Workspaces.
6. Record what should be built, monitored, deferred, or discarded.
7. Move the horizon forward by one month while preserving a 24–36 month forward view.

## Layer model

Current layers may evolve approximately as:

Infrastructure
→ Agent Runtime
→ Tools / Skills
→ Logic
→ Configuration
→ Capability Bundles
→ Agent Workspaces
→ Agent Discovery
→ Agent-to-Agent / Marketplace orchestration
→ higher-order coordination and verification layers

This is a working model, not a claim about the final market structure.

## Selection criteria

A candidate future layer is retained when evidence indicates:

- multiple independent implementations are converging on it;
- it solves a recurring agent-system problem;
- it creates a distinct abstraction above existing infrastructure;
- it can be represented as a product or capability;
- it can be tested and verified;
- it creates a defensible interface or data position.

## Evidence discipline

Classify observations as:

OBSERVED
EMERGING
CONVERGING
HYPOTHETICAL
NOT_YET_VERIFIED

Never promote an emerging trend to a product requirement without evidence.

## Product translation

For every monthly cycle, maintain:

Signal
→ Emerging Layer
→ Required Capability
→ Candidate Logic
→ Candidate Bundle
→ Candidate Workspace
→ Integration Surface
→ Verification Method
→ Commercial Model

## Strategic rule

Do not attempt to predict the market three years in advance once.

Always maintain the next 24–36 months as a moving target.

The objective is to remain approximately two years ahead of the current product layer while validating the direction every month.
