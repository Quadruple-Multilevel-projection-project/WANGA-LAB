# WANGA Logic Fractal Autonomous Research Platform V2

Status: research infrastructure defined; first model not ready.

The objective is to collect accessible source materials, extract source-grounded logical units, compose typed recursive logical fractals, run counterexamples and benchmarks, curate the Logic Wiki, report readiness, and continue versioned upgrades after the first candidate. A candidate is not a verified model.

The source-first order is: source lineage → literal extraction → semantic structure → relation extraction → first-order logic → second-order/meta-level review → closure and contradiction checks → configuration → weights. Weights and geometric similarity must not invent missing relations.

Conversation intake scans only explicit export files or approved excerpts made available to the repository. It does not automatically access all private conversation history. Raw transcripts are not public wiki content. The first model remains blocked until the configured readiness gate passes.
